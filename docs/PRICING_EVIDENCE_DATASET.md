# iPhone Cashify quotation evidence: dataset report

Generated by `scripts/pricing-evidence/render_dataset_reports.py` from `data/pricing-evidence/`. Every figure below is computed from the archives; nothing is typed in by hand.

## 1. What was read, and how

- **57 ZIP archives**, 150 members. Archives were read in memory only; bundled `.py` files (10) were hashed but never executed or imported, and `.html` files (20) were only used for the cross-check below.
- Byte-identical archives (SHA-256): 1 pair(s): Cashify_iPhone16Plus_Full_Checklist (1).zip = Cashify_iPhone16Plus_Full_Checklist.zip.
- The source archives were not modified. The normalized data keeps the archive, member filename and case id of every record (`observations.jsonl`, `measurements.jsonl`).
- **JSON, TXT and HTML are one dataset.** In the 10 archives that ship all three, 960 TXT-table prices were compared with the JSON (0 mismatches) and every JSON selling price appears in the HTML (0 archives with missing figures). The HTML carries selling prices only, not payouts.

Other audit statements checked:

- File names and 'observed live' labels prove nothing about authenticity. Two items need your attention: (a) every iPhone 18 Pro / Pro Max Get Upto is a round thousand (e.g. 120,000, 127,000, 137,000, 165,000), which looks like a placeholder price list rather than market quotes, and the source files themselves say the names are 'reproduced as displayed by Cashify; this tests its quotation flow, not product specifications or release status'; (b) the catalog's own iPhone 18 base prices are those same round numbers.

## 4. Conflicts: identical inputs, different prices

3 configurations have more than one distinct price:

- `iPhone 16|512|yes|yes|yes|no|yes|yes|not_asked|not_asked|not_shown|`: 2026-10-17 sell 44760 (iPhone_16_512GB_24_Test_Cases (1).zip); 2026-10-24 sell 45210 (Cashify_iPhone16_Full_Checklist.zip)
- `iPhone 16 Plus|512|yes|yes|yes|no|yes|yes|not_asked|not_asked|not_shown|`: 2026-10-17 sell 45470 (iPhone_16_Plus_512GB_24_Test_Cases.zip); 2026-10-24 sell 45880 (Cashify_iPhone16Plus_Full_Checklist (1).zip)
- `iPhone 18 Pro|256|yes|yes|yes|yes|yes|yes|yes|not_asked|Below 3 months|`: 2026-10-17 sell 119980 (iPhone_18_Pro_256GB_25_Test_Cases.zip); 2026-10-23 sell 120980 (Cashify_iPhone18_Pro_Pricing.zip); 2026-10-23 sell 120980 (Cashify_iPhone18_Pro_Pricing.zip)

The first two are Cashify moving its Get Upto between 17 and 24 Oct (+1.0%): the same condition quotes ~1% higher a week later, which is why every comparison here uses the reference of its own day. The third is a flawless baseline that read 119,980 on 17 Oct and 120,980 on 23 Oct for the iPhone 18 Pro 256 GB: a Get Upto change of the same kind (120,000 -> 121,000), not a defect deduction.

## 6. Catalog validation

All 57 model/variant labels in the quotes resolve to a catalog entry by model + capacity (nothing was silently mapped); 38 carry a flag:
- `RAM_MISMATCH`: 25 variants
- `STORAGE_SPELLING_DIFFERS`: 8 variants
- `CATALOG_BASE_PRICE_FAR_FROM_CASHIFY`: 6 variants

Details per variant: `reports/catalog_validation.csv`. In particular the catalog's `ram` field is the placeholder `4GB` for every iPhone, the iPhone 18 variants use a different storage spelling (`12 GB/256 GB`) from the rest (`256GB`), and the catalog base price is >5% away from the observed Cashify Get Upto for some variants (listed).
